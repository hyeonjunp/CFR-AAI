# 실제 학습 데이터 기준 중쇄·경쇄 CDR 분포

기준: `dataset/heavy/all_with_cluster_fold.csv.gz`, `dataset/light/all_with_cluster_fold.csv.gz`  
`all_with_cluster_fold`는 클러스터링/중복 제거 후 데이터이며, 각 fold에서 train/valid/test로 나뉩니다.

## 데이터 개수

| 체인 | 전체 학습 후보 | 한 fold train | valid | test |
|---|---:|---:|---:|---:|
| 중쇄(Heavy) | 2,538,365 | 1,523,019 | 507,673 | 507,673 |
| 경쇄(Light) | 1,377,062 | 826,237 | 275,412 | 275,413 |

즉, 실제 모델 학습에 사용하는 `train.csv.gz`는 한 fold 기준으로 중쇄 1,523,019개, 경쇄 826,237개입니다. `all_with_cluster_fold.csv.gz` 전체를 학습에 넣는다는 뜻은 아닙니다.

## 전체 서열 길이(`seq_len`)

아래 수치는 클러스터링 후 전체 학습 후보(`all_with_cluster_fold`) 기준입니다.

| 체인 | 평균±표준편차 | 최소 길이 | P25 | 중앙값 | P75 | 최대 길이 |
|---|---:|---:|---:|---:|---:|---:|
| 중쇄(Heavy) | 122.68 ± 4.05 aa | 90 | 120 | 122 | 125 | 186 |
| 경쇄(Light) | 108.87 ± 2.38 aa | 80 | 107 | 108 | 110 | 127 |

참고로 fold별 train 파일에서는 분할에 따라 최대값이 조금 달라질 수 있습니다. 예를 들어 `fold_0/train.csv.gz`는 중쇄 90–158 aa, 경쇄 80–127 aa입니다.

## CDR1·CDR2·CDR3 평균 위치

위치는 전체 학습 후보 서열의 0-based index이며, 끝 위치는 exclusive입니다. 즉 `[시작, 끝)`으로 해석합니다.

| 체인 | 부위 | 평균 시작 위치 | 평균 끝 위치 | 평균 길이 |
|---|---|---:|---:|---:|
| 중쇄(Heavy) | CDR1 | 24.97 | 33.32 | 8.35 aa |
| 중쇄(Heavy) | CDR2 | 50.32 | 58.14 | 7.82 aa |
| 중쇄(Heavy) | CDR3 | 96.14 | 111.70 | 15.56 aa |
| 경쇄(Light) | CDR1 | 25.54 | 33.19 | 7.65 aa |
| 경쇄(Light) | CDR2 | 50.19 | 53.26 | 3.07 aa |
| 경쇄(Light) | CDR3 | 89.29 | 98.97 | 9.67 aa |

개별 서열마다 V 유전자와 CDR 길이에 따라 위치는 달라지므로, 위 값은 전체 학습 후보에 대한 평균 위치입니다.

## FR(프레임워크)·CDR 평균 위치 및 길이 (전체 구간)

서열 전체를 FR1–CDR1–FR2–CDR2–FR3–CDR3–FR4 순서로 이어붙인 기준입니다.
위치는 0-based, 끝 위치는 exclusive(`[시작, 끝)`)이며, FR*_end == 다음 CDR_start,
FR*_start == 이전 CDR_end 로 이어집니다 (구간 사이 gap 없음, 각 행에서
FR1+CDR1+FR2+CDR2+FR3+CDR3+FR4 길이 합 == `seq_len` 확인됨).

| 체인 | 구분 | 평균 시작 위치 | 평균 끝 위치 | 길이 (aa) 평균±표준편차 | 학습 후보 서열 수 |
|---|---|---:|---:|---:|---:|
| 중쇄(Heavy) | 전체 서열 | - | - | 122.68 ± 4.05 | 2,538,365 |
| | FR1 | 0.00 | 24.97 | 24.97 ± 0.45 | |
| | CDR1 | 24.97 | 33.32 | 8.35 ± 0.76 | |
| | FR2 | 33.32 | 50.32 | 17.00 ± 0.11 | |
| | CDR2 | 50.32 | 58.14 | 7.82 ± 0.75 | |
| | FR3 | 58.14 | 96.14 | 38.00 ± 0.17 | |
| | CDR3 | 96.14 | 111.70 | 15.56 ± 3.95 | |
| | FR4 | 111.70 | 122.68 | 10.98 ± 0.19 | |
| 경쇄(Light) | 전체 서열 | - | - | 108.87 ± 2.38 | 1,377,062 |
| | FR1 | 0.00 | 25.54 | 25.54 ± 0.81 | |
| | CDR1 | 25.54 | 33.19 | 7.65 ± 1.94 | |
| | FR2 | 33.19 | 50.19 | 17.00 ± 0.09 | |
| | CDR2 | 50.19 | 53.26 | 3.07 ± 0.53 | |
| | FR3 | 53.26 | 89.29 | 36.03 ± 0.27 | |
| | CDR3 | 89.29 | 98.97 | 9.67 ± 1.16 | |
| | FR4 | 98.97 | 108.87 | 9.91 ± 0.37 | |

FR2·FR3는 IMGT 넘버링 특성상 길이가 거의 고정적입니다(FR2 = 17 aa로 표준편차 0.1대,
FR3도 중쇄 38/경쇄 36 aa 중심으로 변이가 작음). 반면 FR1·FR4는 V/J 유전자 5'·3' 말단
정렬 차이로 CDR1·CDR3보다는 작지만 FR2·FR3보다 큰 변이를 보입니다. 최소–최대·중앙값
등 세부 분포는 `dataset/*/all_with_cluster_fold.csv.gz`의 `FR1`~`FR4` 컬럼(서열 자체)에서
직접 재계산할 수 있습니다.

## 결론

- 실제 train 개수는 한 fold 기준 중쇄 1,523,019개, 경쇄 826,237개입니다.
- 중쇄 CDR3는 12–20 aa 구간이 중심이고, 경쇄 CDR3는 9–11 aa에 87.18%가 집중됩니다.
- 경쇄 CDR2는 3 aa가 98.25%로 거의 고정되어 있습니다.
